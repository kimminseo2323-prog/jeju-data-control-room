# 설치·실행 매뉴얼 (Windows 11)

명령어를 몰라도 따라 할 수 있게 썼습니다. 필요한 것은 **인터넷 연결**과 **디스크 여유 공간 약 7GB**입니다(패키지 약 1GB, 판단 모델 4.6GB).
검증 환경: Windows 11, Python 3.12, Ollama 0.40. 깨끗한 폴더에서 `install.bat` 실행 → 약 2분 30초 만에 설치가 끝났습니다(패키지 내려받기 시간 포함, 2026-11-11).

---

## 1단계. 파이썬 3.12 설치 (처음 한 번)
1. https://www.python.org/downloads/windows/ 에서 **Python 3.12.x**의 "Windows installer (64-bit)"를 내려받습니다.
2. 설치 첫 화면 아래의 **"Add python.exe to PATH"에 체크**한 뒤 **Install Now**를 누릅니다.
3. 이미 3.12가 설치되어 있다면 이 단계는 건너뜁니다.

## 2단계. 로컬 판단 모델 설치 (처음 한 번, 권장)
원인 판정과 질문 분류를 맡는 작은 AI 모델(tev1)을 이 PC에 설치합니다. **설치하지 않아도 프로그램은 실행되며**, 이 경우 규칙 기반으로 대신 판정합니다.
1. https://ollama.com/download 에서 Windows용 Ollama를 내려받아 설치합니다. 설치가 끝나면 Ollama가 백그라운드에서 자동으로 실행됩니다.
2. 3단계의 `install.bat`이 모델(`tev1:4b`, 4.6GB)을 자동으로 받습니다. 직접 받으려면 명령 창에서 `ollama pull tev1:4b`를 입력합니다.

> 메모리나 디스크가 부족하면 작은 모델 `tev1:0.8b`(833MB)를 쓸 수 있습니다. `ollama pull tev1:0.8b`로 받은 뒤 `.env` 파일의 `JUDGE_MODEL=tev1:0.8b`로 바꿉니다. 다만 정확도가 낮습니다. 처음 보는 질문 분류 정확도는 4B 83%, 0.8B 58%입니다.

## 3단계. 프로그램 설치 (처음 한 번)
1. 제출 파일(zip)을 원하는 곳에 압축 해제합니다. 폴더 이름에 한글이 있어도 됩니다.
2. 폴더 안의 **`install.bat`을 더블클릭**합니다.
3. 검은 창에 `[1/4]`부터 `[4/4]`까지 진행되고, "설치가 끝났습니다"가 보이면 아무 키나 눌러 닫습니다.

## 4단계. 실행 (사용할 때마다)
1. **`run.bat`을 더블클릭**합니다.
2. 잠시 뒤 브라우저에 `http://127.0.0.1:8501` 화면이 열립니다. 열리지 않으면 주소창에 직접 입력합니다.
3. 끝낼 때는 검은 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.

> 화면은 이 PC에서만 열립니다(`127.0.0.1`). 같은 네트워크의 다른 PC에서는 접속할 수 없습니다.

## 사용법
**왼쪽 사이드바**
- **신호**: 유동인구·와이파이·버스 중 하나를 고릅니다.
- **탐지 방법**: '같은 요일 중앙값 기준'과 'STL 분해 잔차' 중에서 고릅니다.
- **민감도**: 숫자가 높을수록 큰 변화만 이상으로 봅니다.
- **원인 판정 모델**: '연결됨 · tev1:4b (로컬)'이면 판단 모델이 동작 중입니다.

**관제판**
- 빨간 칸은 평소보다 많은 날, 파란 칸은 적은 날입니다. 회색 빈칸은 수집되지 않은 날입니다.
- 아래 표는 이상 구간입니다. 점수가 큰 순으로 정렬됩니다.

**상세 분석·브리핑**
1. 이상 구간을 고르면 그래프, 같은 날 맥락(기상·공휴일·성수기), 다른 신호와 제주 전체의 동반 변화가 나옵니다.
2. **원인 판정 실행**을 누르면 원인 후보와 확률이 나옵니다. '판정 모델에 넘긴 근거'를 펼치면 모델이 본 내용을 그대로 확인할 수 있습니다.
3. **브리핑**에는 문장마다 근거 표시([R1] 등)가 붙어 있고, 맨 위에 검증 결과(✅/⚠️)가 표시됩니다.
4. 결과는 '결과 폴더(data/results)에 저장'하거나 '내 PC로 내려받기'로 보관합니다.

**질문하기**
- 예시 버튼을 누르거나 직접 입력한 뒤 **질문 보내기**를 누릅니다.
- 예: "7월에 유동인구가 이상하게 많았던 곳 알려줘", "이호동 7월 28일에 사람이 왜 이렇게 많았어?", "버스 데이터는 어디서 가져온 거야?"
- 질문에 **읍면동 이름**(예: 이호동, 애월읍)과 **날짜나 달**(예: 7월 28일, 12월 말)을 넣으면 더 정확하게 답합니다.
- 검증을 통과하지 못한 답변은 보여 주지 않고 "답변 보류"로 표시합니다.

**데이터 품질**
- 신호별 마지막 날짜와 위치 매핑 결과(매칭 실패 건수)를 확인합니다.

**저장 결과 삭제**
- 사이드바의 '화면 종료 시 저장한 브리핑 삭제'가 켜져 있으면(기본값), 화면을 끌 때 이번에 저장한 브리핑을 지웁니다.
- '지금 삭제' 버튼을 누르면 바로 지웁니다.

## (선택) 최신 데이터 다시 받기
기본 데이터는 `data/cache`에 들어 있습니다. 새로 받으려면 제주데이터허브 프로젝트키가 필요합니다.
1. jejudatahub.net에 로그인합니다. 사용할 데이터 상세 페이지에서 **프로젝트 담기**를 누릅니다.
2. **마이페이지 > 프로젝트 관리**에서 프로젝트키를 확인합니다.
3. 폴더의 `.env` 파일을 메모장으로 열어 `JEJU_HUB_PROJECT_KEY=` 뒤에 키를 붙여 넣습니다. **키는 다른 사람에게 보내지 마세요.**
4. 폴더 주소창에 `cmd`를 입력해 명령 창을 열고, `.venv\Scripts\python -m app.ingest.plan`을 실행합니다.
5. 하루 호출 한도(데이터별 기본 1,000회, 증설 승인을 받으면 `app/ingest/jobs.py`의 `daily_quota` 값을 바꿉니다)에 걸리면 받던 곳을 저장하고 멈춥니다. 다음 날 같은 명령을 실행하면 이어서 받습니다.

## 문제 해결
| 증상 | 해결 |
|---|---|
| install.bat에서 "파이썬 3.12를 찾지 못했습니다" | 1단계를 다시 하고 "Add python.exe to PATH"에 체크했는지 확인 |
| "패키지 설치에 실패했습니다" | 인터넷 연결 확인 후 install.bat 다시 실행(받던 것부터 이어서 설치) |
| 사이드바에 "연결 안 됨 → 규칙 기반 판정" | 작업 표시줄 오른쪽에 Ollama 아이콘이 있는지 확인. 없으면 시작 메뉴에서 Ollama 실행 |
| 사이드바에 "tev1:4b 모델이 설치되지 않음" | 명령 창에서 `ollama pull tev1:4b` |
| 원인 판정이 느림(수 초) | 그래픽카드 메모리가 작으면 CPU로 계산합니다. CPU만 쓸 때 판정 1건 약 4초, 질문 분류 약 2.5초(측정값) |
| run.bat 창에 "Port 8501 is already in use" | 이미 열린 run.bat 창이 있는지 확인하고 닫은 뒤 다시 실행 |
| 화면에 "이 신호는 아직 분석할 만큼 수집되지 않았습니다" | 해당 신호의 데이터가 28일 미만입니다. 다른 신호를 고르거나 데이터를 더 받으세요 |
| 질문 답변이 "검증을 통과하지 못해 표시하지 않습니다" | 숫자가 계산 결과와 맞지 않아 보류한 것입니다. '근거' 펼침에서 계산 결과를 직접 확인하세요 |

## 삭제
- 폴더를 통째로 지우면 프로그램이 삭제됩니다.
- 판단 모델은 명령 창에서 `ollama rm tev1:4b`를 입력해 지웁니다. Ollama 자체는 Windows 설정 > 앱에서 제거합니다.
