# 설치·실행 매뉴얼 (Windows 11)

명령어를 몰라도 따라 할 수 있게 썼습니다. 필요한 것은 **인터넷 연결**과 **디스크 여유 공간 약 7GB**입니다(패키지 약 1GB, 판단 모델 4.6GB).
검증 환경: Windows 11, Python 3.12, Ollama 0.40. 제출 압축본을 빈 폴더에 풀고 `1_설치.bat` 실행 → 약 2분 30초 만에 설치가 끝났습니다(패키지 내려받기 시간 포함, 2026-11-12).

---

## 1단계. 파이썬 3.12 (자동 설치)
따로 할 일이 없습니다. 3단계의 `1_설치.bat`이 파이썬 3.12를 찾지 못하면, 함께 들어 있는 공식 설치 파일(`프로그램\installer\python-3.12.10-amd64.exe`, python.org 배포본)로 이 사용자 계정에 자동 설치합니다. 관리자 권한은 필요 없고 1~3분 걸립니다.
- 이미 3.12가 있으면 그것을 씁니다.
- 자동 설치가 실패하면 같은 설치 창이 열립니다. 첫 화면 아래 **"Add python.exe to PATH"에 체크**하고 **Install Now**를 누른 뒤, `1_설치.bat`을 다시 실행하세요.

## 2단계. 로컬 판단 모델 설치 (처음 한 번, 권장)
원인 판정과 질문 분류를 맡는 작은 AI 모델(tev1)을 이 PC에 설치합니다. **설치하지 않아도 프로그램은 실행되며**, 이 경우 규칙 기반으로 대신 판정합니다.
1. https://ollama.com/download 에서 Windows용 Ollama를 내려받아 설치합니다. 설치가 끝나면 Ollama가 백그라운드에서 자동으로 실행됩니다.
2. 3단계의 `1_설치.bat`이 모델(`tev1:4b`, 4.6GB)을 자동으로 받습니다. 직접 받으려면 명령 창에서 `ollama pull tev1:4b`를 입력합니다.

> 메모리나 디스크가 부족하면 작은 모델 `tev1:0.8b`(833MB)를 쓸 수 있습니다. `ollama pull tev1:0.8b`로 받은 뒤 `.env` 파일의 `JUDGE_MODEL=tev1:0.8b`로 바꿉니다. 다만 정확도가 낮습니다. 처음 보는 질문 분류 정확도는 4B 83%, 0.8B 58%입니다.

## 3단계. 프로그램 설치 (처음 한 번)
1. 제출 파일(zip)을 원하는 곳에 압축 해제합니다. 폴더 이름에 한글이 있어도 됩니다. 풀면 이렇게 보입니다.
```
숨비소리/
├─ 0_먼저_읽어주세요.txt   처음 볼 안내
├─ 1_설치.bat              처음 한 번 더블클릭
├─ 2_실행.bat              쓸 때마다 더블클릭
├─ 문서/                   결과보고서(화면과 사용법), 설치·실행 매뉴얼, 결과 설명서, 기획서, 데이터 활용 명세(PDF)
└─ 프로그램/               실행 소스·데이터·평가(직접 열 필요 없음)
```
2. **`1_설치.bat`을 더블클릭**합니다(안에서 `프로그램\install.bat`을 실행합니다).
3. 검은 창에 `[1/4]`부터 `[4/4]`까지 진행되고, "설치가 끝났습니다"가 보이면 아무 키나 눌러 닫습니다.

## 4단계. 실행 (사용할 때마다)
1. **`2_실행.bat`을 더블클릭**합니다(안에서 `프로그램\run.bat`을 실행합니다).
2. 잠시 뒤 브라우저에 `http://127.0.0.1:8501` 화면이 열립니다. 열리지 않으면 주소창에 직접 입력합니다.
   - 전체 화면이 다 뜨기까지 PC 사양에 따라 **1분~최대 5분쯤** 걸립니다. 실행할 때마다 데이터를 읽고 43개 읍면동의 이상 점수를 새로 계산하기 때문입니다. 브라우저가 먼저 열려 빈 화면이나 '계산 중'이 보여도 기다리면 됩니다.
   - 검은 창이 프로그램입니다. 쓰는 동안 닫지 마세요. 창을 켜 둔 채 새로고침하면 1~2초 만에 열립니다.
3. 끝낼 때는 검은 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.

> 화면은 이 PC에서만 열립니다(`127.0.0.1`). 같은 네트워크의 다른 PC에서는 접속할 수 없습니다.

## 사용법
화면마다 번호를 붙인 캡처로 보려면 `문서/결과보고서.pdf`를 보세요. 여기에는 요점만 적습니다.

**왼쪽 사이드바**
- **신호**: 유동인구·와이파이·버스·외국인 중 하나를 고릅니다.
- **평소 값(기대값) 계산**: '앞뒤 4주 같은 요일의 중앙값'(기본)과 'STL 분해(추세+요일 주기)' 중에서 고릅니다.
- **민감도**: 점수가 이 값 이상이면 이상으로 봅니다. 높을수록 큰 변화만 남습니다.
- **원인 판정 모델**: 'tev1:4b 연결됨(이 PC)'이면 판단 모델이 동작 중입니다.

**관제판**
- 기간(월)을 고르면 그 달의 요약 문장, 읍면동 지도(어디서), 주요 이상 TOP 5, 날짜별 그래프(언제)가 나옵니다.
- 지도는 읍면동 경계를 칠한 것입니다. 빨강은 평소보다 많았던 곳, 파랑은 적었던 곳이고 진할수록 변화가 큽니다. 마우스 휠로 확대할 수 있습니다.
- TOP 5의 '상세 분석 보기'를 누르면 그 구간이 상세 분석 탭에 선택됩니다.
- 접힌 칸을 열면 읍면동 × 날짜 점수표와 이상 구간 전체 목록이 있습니다.

**상세 분석·브리핑**
1. 이상 구간을 고르면 제목 문장, 그래프(기본은 구간 앞뒤 8주, '전체 기간'으로 바꿀 수 있음), 같은 날 맥락(기상·공휴일·성수기), 함께 움직인 신호가 나옵니다. 근거마다 '확인됨·기록 없음·확인 불가'가 붙습니다.
2. **원인 판정 실행**을 누르면 원인 후보와 확률이 나옵니다. '판정 모델에 넘기는 근거'를 펼치면 모델이 본 내용을 그대로 확인할 수 있습니다.
3. **브리핑**에는 문장 끝에 근거 번호(작은 R1, R2 등)가 붙어 있고, 맨 위에 검증 결과(검증 통과/미통과)가 표시됩니다.
4. 결과는 '결과 폴더(data/results)에 저장'하거나 '내 PC로 내려받기'로 보관합니다.

**질문하기**
- 예시 질문을 누르거나 직접 입력한 뒤 **질문 보내기**를 누릅니다.
- 예: "7월에 유동인구가 이상하게 많았던 곳 알려줘", "이호동 2024년 7월 28일에 사람이 왜 이렇게 많았어?", "송산동 2024년 9월 29일에 외국인이 왜 많았어?", "버스 데이터는 어디서 가져온 거야?"
- 연도를 빼고 물으면(예: "7월에") 데이터 기간(2024-04~2026-08) 안의 가장 최근 해로 봅니다. 답변 첫 줄에 실제로 본 기간이 나옵니다.
- 질문에 **읍면동 이름**(예: 이호동, 애월읍)과 **날짜나 달**(예: 7월 28일, 12월 말)을 넣으면 더 정확하게 답합니다.
- 검증을 통과하지 못한 답변은 보여 주지 않고 "답변 보류"로 표시합니다.

**데이터 품질**
- 신호별 마지막 날짜, 위치 매핑 결과(매칭 실패 건수), 버스 이용 자료의 읍면동 연결 비율, 지도 경계 출처를 확인합니다.

**저장 결과 삭제**
- 사이드바의 '화면 종료 시 저장한 브리핑 삭제'가 켜져 있으면(기본값), 화면을 끌 때 이번에 저장한 브리핑을 지웁니다.
- '지금 삭제' 버튼을 누르면 바로 지웁니다.

## (선택) 최신 데이터 다시 받기
기본 데이터는 `data/cache`에 들어 있습니다. 새로 받으려면 제주데이터허브 프로젝트키가 필요합니다.
1. jejudatahub.net에 로그인합니다. 사용할 데이터 상세 페이지에서 **프로젝트 담기**를 누릅니다.
2. **마이페이지 > 프로젝트 관리**에서 프로젝트키를 확인합니다.
3. `프로그램` 폴더의 `.env` 파일을 메모장으로 열어 `JEJU_HUB_PROJECT_KEY=` 뒤에 키를 붙여 넣습니다. **키는 다른 사람에게 보내지 마세요.**
4. `프로그램` 폴더 주소창에 `cmd`를 입력해 명령 창을 열고, `.venv\Scripts\python -m app.ingest.plan`을 실행합니다.
5. 하루 호출 한도(데이터별 기본 1,000회, 증설 승인을 받으면 `app/ingest/jobs.py`의 `daily_quota` 값을 바꿉니다)에 걸리면 받던 곳을 저장하고 멈춥니다. 다음 날 같은 명령을 실행하면 이어서 받습니다.

## 문제 해결
| 증상 | 해결 |
|---|---|
| 1_설치.bat에서 "파이썬 3.12를 자동으로 설치하지 못했습니다" | 함께 열리는 파이썬 설치 창에서 "Add python.exe to PATH"에 체크하고 Install Now. 설치 뒤 창을 닫고 1_설치.bat을 다시 실행. 설치 파일이 없다는 안내가 나오면 압축을 다시 풀기 |
| "패키지 설치에 실패했습니다" | 인터넷 연결 확인 후 1_설치.bat 다시 실행(받던 것부터 이어서 설치) |
| 사이드바에 "연결 안 됨 → 규칙 기반 판정" | 작업 표시줄 오른쪽에 Ollama 아이콘이 있는지 확인. 없으면 시작 메뉴에서 Ollama 실행 |
| 사이드바에 "tev1:4b 모델이 설치되지 않음" | 명령 창에서 `ollama pull tev1:4b`. 그래도 같으면 11434 포트를 Ollama가 아닌 다른 프로그램이 쓰고 있을 수 있습니다(개발 PC에서 실제로 있었음). 이때 이 프로그램은 그 주소로 질문·근거를 보내지 않고 규칙 기반으로 동작합니다. Ollama를 다른 포트로 띄웠다면 `.env`의 `JUDGE_HOST`를 그 주소로 바꾸세요 |
| 전체 화면이 뜨기까지 1분~최대 5분 | 실행할 때마다 데이터를 읽고 43개 읍면동의 이상 점수와 문서 색인을 계산합니다. 걸리는 시간은 PC 사양에 따라 다릅니다(참고: 개발 PC 약 20초, 11/12 깨끗한 폴더 설치 재현 약 35초). 계산 결과는 검은 창이 켜져 있는 동안만 기억하므로, 창을 켜 둔 채 새로고침하면 1~2초 만에 열리고 창을 닫았다 다시 실행하면 다시 계산합니다 |
| 질문 답변이 느림(10초 남짓) | 그래픽카드 메모리가 작으면 판단 모델을 CPU로 계산합니다. 6코어 CPU로 묶어 잰 값은 원인 질문 약 14초, 다른 질문 약 5초입니다(개발 PC 측정, 센터 PC 실측 아님). 첫 질문은 모델을 메모리에 올리느라 몇 초 더 걸립니다 |
| 2_실행.bat 창에 "Port 8501 is already in use" | 이미 열린 2_실행.bat 창이 있는지 확인하고 닫은 뒤 다시 실행 |
| 화면에 "이 신호는 아직 분석할 만큼 수집되지 않았습니다" | 해당 신호의 데이터가 28일 미만입니다. 다른 신호를 고르거나 데이터를 더 받으세요 |
| 질문 답변이 "검증을 통과하지 못해 표시하지 않습니다" | 숫자가 계산 결과와 맞지 않아 보류한 것입니다. '근거' 펼침에서 계산 결과를 직접 확인하세요 |

## 제약사항
- Windows 11에서 만들고 시험했습니다. 설치·실행 파일(`.bat`)은 Windows용이며, macOS·Linux에서는 시험하지 않았습니다.
- 파이썬 3.12가 필요합니다. 없으면 1_설치.bat이 함께 들어 있는 3.12.10을 이 사용자 계정에 설치합니다(다른 버전의 파이썬은 그대로 둡니다).
- 처음 설치할 때 인터넷이 필요합니다(파이썬 패키지, 판단 모델 4.6GB). 파이썬 자체는 결과물에 들어 있습니다.
- 화면은 이 PC에서만 열립니다(`127.0.0.1`).
- 판단 모델이 없으면 규칙 기반으로 동작합니다. 이때 질문 분류 정확도가 낮아집니다(설계에 쓰지 않은 질문 12개에서 tev1:4b 83%, 키워드 규칙 33%, 결과 설명서 5.3).
- 들어 있는 데이터는 제출 시점 수집본입니다(유동인구 2024-04~2026-08). 새 데이터를 받으려면 허브 프로젝트 키가 필요합니다('(선택) 최신 데이터 다시 받기').
- 기상·축제·입도객 자료는 유동인구보다 기간이 짧아, 그 뒤 날짜는 해당 근거를 '확인 불가'로 표시합니다. 분석의 한계는 결과 설명서 6장에 있습니다.

## 삭제
- 압축을 푼 `숨비소리` 폴더를 통째로 지우면 프로그램이 삭제됩니다.
- 판단 모델은 명령 창에서 `ollama rm tev1:4b`를 입력해 지웁니다. Ollama 자체는 Windows 설정 > 앱에서 제거합니다.
