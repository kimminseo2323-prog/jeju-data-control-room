  2. 아래 데이터 페이지를 하나씩 열어 「프로젝트 담기」를 누르고 같은 프로젝트에 담습니다 (프로젝트 이름 예: 숨비소리).

    • 함께 담기(선택 4개): 589 외국인 단기체류 · 611 버스 노선 · 580 방문목적별 입도객 · 582 국가별 입도객
    • 파일 내려받기: 761 축제행사 CSV → 받은 파일을 2611_JEJU\data\manual\ 폴더에 넣어 주세요 (폴더는 만들어 두었습니다).
  3. 상단 마이페이지 → 프로젝트 관리 → 해당 프로젝트에서 프로젝트키를 복사합니다.
  4. 2611_JEJU 폴더의 .env.example 파일을 복사해 이름을 .env로 바꿉니다.
  5. .env를 메모장으로 열어 JEJU_HUB_PROJECT_KEY=여기에_프로젝트키 줄의 여기에_프로젝트키 부분을 복사한 키로 바꾸고 저장합니다.
